# Playbook — Video Brief Generation

**Purpose:** generate a 5–15 second video storyboard for every listing. Etsy 2026 strongly favors listings with video. Video autoplays on mobile (where 46% of purchases happen), drives dwell time, and is a top conversion signal.

**Where it runs:** every MODE 1 and MODE 2 output includes a video brief alongside the image brief.

---

## Video specs (Etsy 2026)

| Spec | Value |
|---|---|
| Length | 5–15 seconds (Etsy enforces; longer is auto-trimmed) |
| Aspect ratio | Square (1:1) preferred; vertical (4:5) acceptable |
| Resolution | 1080×1080 minimum |
| Format | MP4 (H.264) |
| Sound | Allowed but autoplays muted — design for sound-off viewing |
| Text overlay | Strongly recommended (works while muted) |
| Hook timing | Visual hook must happen in the first 2 seconds |

## Storyboard templates by product type

### Digital SVG / clipart bundle (5–8 seconds)

```
00:00–00:01  [Hook]      Wide shot of all designs in the bundle, fanned out or gridded
                          Overlay text: "[N] Designs Included"
00:01–00:03  [Detail]    Cut to a single design close-up, then zoom out to show 2-3 more variations
                          No overlay (designs speak for themselves)
00:03–00:05  [Use case]  Cut to design applied to product (shirt, mug, wall art) — finished result
                          Overlay text: "Make Yours Today" or "Cricut Ready"
00:05–00:07  [CTA]       Bundle overview shot returns with format icons (SVG, PNG, EPS)
                          Overlay text: "Instant Download"
```

### Printable / digital template (6–10 seconds)

```
00:00–00:02  [Hook]      Printed version of the template held up or displayed
                          Overlay text: "[Niche] Printable"
00:02–00:05  [Detail]    Pan across the printed template showing layout / content
                          No overlay
00:05–00:08  [Edit demo] If editable: quick cut of someone editing it in Canva / Word
                          Overlay text: "Edit in [Canva / Word]"
00:08–00:10  [Result]    Final printed/displayed version in context (framed, on a desk, etc.)
                          Overlay text: "Print at home"
```

### Physical product (8–15 seconds)

```
00:00–00:02  [Hook]      Product in lifestyle context — being worn, used, displayed
                          Overlay text: optional product name
00:02–00:06  [Detail]    Close-up of texture, material, key feature
                          No overlay
00:06–00:10  [Scale/Use] Person interacting with product (hand holding, wearing, opening)
                          Overlay text: optional benefit ("Handmade", "Personalized", etc.)
00:10–00:13  [Variants]  Brief shot of other variants/colors/sizes available
                          Overlay text: "Multiple options"
00:13–00:15  [Brand]     Final shot — packaging, logo, or aesthetic "signature" shot
                          Overlay text: shop name or tagline (no Etsy logo)
```

## Rules

1. **Visual hook in 2 seconds.** Mobile auto-scroll feeds skim fast. If the buyer doesn't understand what the product is by second 2, they're gone.
2. **Designed for sound-off.** Always include text overlays for key information. Sound is a bonus, not a requirement.
3. **No Etsy logo, no "Buy Now" calls.** Etsy strips/penalizes overt platform CTAs.
4. **Lifestyle > product-on-white.** Same rule as hero images.
5. **Show the finished result for digital products.** Don't just show the SVG file. Show the t-shirt the SVG made.
6. **Refresh video every 6 months.** Stale video is a CTR drag. Even minor re-edits with new overlay text refresh the algorithm signal.

---

## When to skip video

- **Custom-order listings where each order is unique.** Video doesn't represent any single order. Use multiple photos instead.
- **Adult content / restricted categories.** Etsy may not autoplay; weaker ROI.
- **Vintage one-of-a-kind items.** A single static image with great lighting often outperforms video for collectible items.

For all other listings: include video. The dwell-time + conversion uplift is well-documented.
